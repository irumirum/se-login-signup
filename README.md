# ICSI 418Y - Software Engineering | Homework 01
Login and Signup page using HTML, CSS

## Project Description
This project creates two web pages: Login and Signup<br>

The Login page allows existing users to enter their User ID and Password and log into the system. If the user does not yet have an account, they can navigate to the Signup page.

The Signup page allows new users to create an account by entering their First Name, Last Name, User ID, and Password. Users who already have an account can navigate back to the Login page.
